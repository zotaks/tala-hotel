TALA HOTEL - HOW TO INSTALL ON THIS LAPTOP
==========================================

You only need 2 things: XAMPP and Google Chrome.


FIRST TIME (about 10 minutes)
-----------------------------
1. Install XAMPP
     Go to  https://www.apachefriends.org  -> Download for Windows -> install
     (just click Next until it finishes).

2. Start XAMPP
     Open "XAMPP Control Panel" from the Start menu.
     Click START next to  Apache  and next to  MySQL.
     Wait until both names turn GREEN.

3. Double-click  INSTALL.bat  (in this folder).
     If Windows shows a blue warning, click "More info" -> "Run anyway".

4. The app opens in your browser at:   http://localhost/tala/
     Bookmark this page.


EVERY TIME AFTER THAT
---------------------
1. Open XAMPP Control Panel -> START Apache and MySQL (green).
2. Open your bookmark  http://localhost/tala/


LOGIN

Guests:  use the normal login, or click "Create an account".

   (If records were copied from the old laptop, use the passwords
    you already chose there.)


IF SOMETHING GOES WRONG
-----------------------
"Can't reach the database"  -> Apache and MySQL are not green. Start them in XAMPP.
Page does not open          -> Apache is not green. Click START next to Apache.
Apache will not turn green  -> Close Skype, then click START again, or restart the laptop.
No photos                   -> Connect to the internet.
Locked out (5 wrong tries)  -> Wait 15 minutes, then try again.
